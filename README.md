Architecture Portfolio

A responsive architecture portfolio website designed to present architectural projects through a clean, modern, and visually focused interface.

Overview

This project was developed as a portfolio-oriented web project, focusing on visual composition, responsive design, navigation, and user experience.

Technologies

- HTML5
- CSS3
- JavaScript

Highlights

- Responsive design
- Modern and minimalist interface
- Project showcase
- Structured navigation
- Interactive elements
- Mobile-friendly layout

Purpose

The project was created to practice front-end development while building a complete website with a strong visual identity and a real-world portfolio structure.
